OP/ED detection

Visual guide to the current analysis pipeline in src-tauri/src/op_ed.rs (Chromaprint + ffmpeg). Triggered per title via Detect OP/ED → background job op_ed_detect:{anime_id}.

Job overview

One job processes all non-missing episodes for a title. Work runs on a blocking worker thread; SQLite is only touched in short bursts (never held across ffmpeg/fpcalc).

Start → OP Discovery → OP Match all eps → ED Discovery → ED Match all eps → Done
Requires at least 2 episodes. With fewer, both OP and ED are marked skipped. If discovery finds no repeated segment and there are ≥ 3 episodes, the title may be flagged no_op_ed. After 3 consecutive match failures mid-run, matching can stop early.

Fingerprint pipeline

Every audio extract follows the same path. Results are cached on disk under data/op-ed/fingerprints/{key}.fp.

ffmpeg
Mono PCM 11025 Hz, -ss + -t on video file
fpcalc
Chromaprint raw signed JSON vector (~8 fps)
Cache
Key cp2_{pathHash}_{startMs}_{durMs}
Compare
Hamming similarity per subfingerprint (32-bit XOR)

Phase 1 — Discovery (per OP or ED)

Goal: find a 15-second audio snippet that appears similarly in at least two different episodes, then use it to build a 90s template.

OP Where we listen (example 24 min episode)

180s discovery region (one ffmpeg decode) 15s seed windows every 7.5s (sliced in memory)

ED Tail region

Discovery steps

  1. Take up to 4 episodes from the start of the sorted list.
  2. For each: decode one region (OP: first 180s, ED: last 180s) → one fingerprint.
  3. Slice ~23 overlapping 15s windows (step 7.5s) from that fingerprint — no extra ffmpeg.
  4. Compare all seed pairs; pick the cluster matching the most distinct episodes (≥ 2).
  5. Build template: 90s fingerprint at the winning seed’s start_sec.

Phase 2 — Match (every episode)

Slide the 90s template along each episode’s fingerprint. Search is conservative: best offset must pass average, strong-frame ratio, and lower-quartile checks.

OP Optimistic match

Decode min(duration, 180 + 90) ≈ 270s from t=0. Search frames 0 … 180s only.

ED Optimistic match

Decode ~270s ending at file end (-ss near tail). Search maps to last 180s of timeline.

Up to 4 episodes run ffmpeg/fpcalc in parallel during matching (rayon). DB writes stay serial. Re-runs are fast when .fp cache keys still match file mtime/size.
